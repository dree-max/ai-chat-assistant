# Lab guide: Build your first ai-chat-assistant

## Goal
Build a simple AI Chat Assistant that can run on ollama by default and switch to OpenAI when needed.

This lab gives us a working app that we can test in the next demo

## What are you Building
You are building a small streamlit app

The app lets a user type a message, sends the message to a model, and shows the assistant response.

The model provider is flexible;

 - Ollama for local development
 - OpenAI for cloud model testing
